# AskPupkin — платформа вопросов и ответов

**AskPupkin** — это веб-приложение на Django, где пользователи могут задавать вопросы, отвечать на них, ставить лайки, фильтровать по тегам и просматривать «горячие» вопросы. Проект создан в рамках учебного курса VK Web.

## Возможности

- Просмотр списка вопросов (главная страница, «горячие» вопросы, вопросы по тегам)
- Пагинация (по 5 элементов на страницу)
- Детальная страница вопроса с ответами
- Форма для создания нового вопроса (с валидацией полей и тегов)
- Регистрация и авторизация пользователей
- Личный кабинет с возможностью смены аватара, почты, никнейма и пароля
- Боковая панель с популярными тегами и лучшими участниками

## Технологии
- Python 3.10+
- Django 5.1.1
- Bootstrap 5 (адаптивная вёрстка)
- SQLite (по умолчанию, можно заменить на PostgreSQL/MySQL)

# Как запустить
### Локально
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python3 manage.py migrate
python3 manage.py runserver

## Запуск через Docker

1. Собрать образы:
   ```bash
   docker-compose build

2. Запустить контейнеры в фоновом режиме:
bash

docker-compose up -d

3. Применить миграции:
bash

docker-compose exec web python manage.py migrate

4. Сайт доступен по адресу http://localhost:8000.
